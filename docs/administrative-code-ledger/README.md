# 行政区划代码历史核验台账

本目录按省级行政区划分别维护六位行政区划代码历史台账，保留已废止代码、历史名称、年度在册范围、变更事件与可追溯的证据链接。

## 目录

- [11 北京市](./11-北京市.md) — 1981—2025 年第三方年度快照已核对；1980—1982 年县码边界冲突待原始国家标准裁决。
- [12 天津市](./12-天津市.md) — 32 个历史代码；14 个关键年份快照抽核，1980—1982 年县码边界冲突待裁决。

后续按省级代码依次新增 `12-天津市.md`、`13-河北省.md` 等；特别行政区及特殊编码独立核验。

## 核验规范

1. 每省独立 Markdown，按六位代码升序，保留所有已知历史记录。
2. 代码表中的年份与行政区划批复日期分开：**首次/最后在册年份不等于精确启停日期**。
3. 优先原始国家标准、国务院批复、省市政府及民政部门公告；第三方历史快照只能作为辅助证据。
4. 对同码更名、行政范围调整、代码替换和数据源冲突分别记录，不凭空构造一对一映射。
5. 冲突保留并列证据、状态和待裁决事项；未经确认不改动运行时 JSON。
6. 文档附逐地区变更事件、官方来源链接和本省变更记录。

## 验收标准

只有完成历年数据并集、代码及名称逐年核对、权威证据交叉核验、冲突裁决后，才标记省份为「最终验收」。

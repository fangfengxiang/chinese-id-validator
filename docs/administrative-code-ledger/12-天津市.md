3. **国务院《关于同意天津市调整部分行政区划的批复》（国函〔2015〕119号）**：2015-07-23，宁河县、静海县撤县设区。[批复文本转载](https://zh.wikisource.org/zh-hans/国务院关于同意天津市调整部分行政区划的批复_(2015年))；需补政府网站原始发布地址。
4. **[yescallop/areacodes](https://github.com/yescallop/areacodes)**：年度快照辅助来源。本轮已抽核 1981、1982、1991、1992、1999、2000、2001、2008、2009、2014、2015、2016、2024、2025 年；**不是 45 年全量审计**。
5. **[项目历史数据](https://github.com/fangfengxiang/chinese-id-validator/blob/main/src/main/resources/data/address_code_timeline.json)**：原始记录基线。
